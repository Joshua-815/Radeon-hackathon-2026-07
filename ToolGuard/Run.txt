TOOLGUARD - INSTANCE STARTUP NOTES
(keep this file in the git repo, NOT just on the instance)

=== IMPORTANT: /workspace does NOT survive a destroy/relaunch ===
Confirmed Aug 1, 2026. Only /persistent actually survives.

=== Every time you get a FRESH instance ===

1) Clone the repo (first time only - if already cloned, just cd + git pull):
   Note: this first clone still needs manual SSH setup since
   restore_ssh.sh doesn't exist yet on a truly blank /persistent.
   See "FIRST EVER SETUP" section below if /persistent is empty.

   cd /persistent
   git clone git@github.com:Joshua-815/Radeon-hackathon-2026-07.git
   cd Radeon-hackathon-2026-07/ToolGuard

2) Run the bootstrap script - does everything else in one command:
   bash scripts/bootstrap.sh

3) Start the model server:
   scripts/start_vllm.sh
   tmux attach -t vllm    (to watch it / detach with Ctrl+B then D)

4) Test it's alive from another shell:
   curl http://localhost:8000/v1/models

=== FIRST EVER SETUP (only if /persistent/restore_ssh.sh doesn't exist) ===

   mkdir -p /persistent/ssh_backup
   ssh-keygen -t ed25519 -C "toolguard-instance" -N "" -f ~/.ssh/id_ed25519
   cat ~/.ssh/id_ed25519.pub
   ## -> copy that line, add it at https://github.com/settings/keys

   cat > ~/.ssh/config << 'SSHEOF'
   Host github.com
     Hostname ssh.github.com
     Port 443
     User git
   SSHEOF

   cp ~/.ssh/id_ed25519 ~/.ssh/id_ed25519.pub ~/.ssh/config /persistent/ssh_backup/

   cat > /persistent/restore_ssh.sh << 'RESTOREEOF'
   #!/bin/bash
   mkdir -p ~/.ssh
   cp /persistent/ssh_backup/id_ed25519 ~/.ssh/
   cp /persistent/ssh_backup/id_ed25519.pub ~/.ssh/
   cp /persistent/ssh_backup/config ~/.ssh/
   chmod 700 ~/.ssh
   chmod 600 ~/.ssh/id_ed25519
   chmod 644 ~/.ssh/id_ed25519.pub ~/.ssh/config
   ssh -T git@github.com
   git config --global user.name "Joshua-815"
   git config --global user.email "<your Joshua-815 email>"
   RESTOREEOF
   chmod +x /persistent/restore_ssh.sh

=== End of every session ===
Commit + push before ending every session, no exceptions:
   cd /persistent/Radeon-hackathon-2026-07/ToolGuard
   git add -A
   git commit -m "description of what you did"
